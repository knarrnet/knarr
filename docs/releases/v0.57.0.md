# v0.57.0 — Structural Debt Retirement

**Release date:** 2026-04-15
**Baseline:** v0.56.1 "Transport Identity Binding"
**Sprint goal:** Retire structural debt accumulated since v0.55.0. No new features.
**Scope:** 21 items, ~711 LOC shipped + ~100 LOC tests

---

## Summary

v0.57.0 retires four categories of structural debt:

- **Infrastructure debt** (Track A): TransportMetadata frozen dataclass, explicit pool wrappers, plugin capability registry, legacy URI metric
- **Security hardening** (Track B): sidecar 64 KB streaming, cert-pin reconnect rate limit, fire-and-forget TLS verification
- **Latent bug fixes** (Track C): 10 items — migration splitter, punchhole log rename, event loop hygiene, WinError 10054 unification, mail startup grace, sample binding bus event, and more
- **Event-loop blocking** (Track D): settlement execution, write-queue polling, and peer-sweep paths all moved off the hot async loop

---

## Shipped items

### Track A — Infrastructure debt

**A-1: TransportMetadata frozen dataclass** (~50 LOC)

`TransportMetadata` converted to `@dataclass(frozen=True)`. All `object.__setattr__` stash patterns removed. `request_response_expecting` helper consolidates 15+ `verify_message` call sites into a single typed entry point, replacing the `request_response` import.

**Files:** `src/knarr/dht/protocol.py`, `src/knarr/dht/node.py`

**A-2: CapabilityRegistry + plugin config schema** (~300 LOC)

`CapabilityRegistry` class added. `PluginContext.register_capability(name, handler)` replaces `get_plugin_by_name("X")._private_attr` pattern. `NODE_CONFIG_SCHEMA` in `cli/config_schema.py` replaces `_KNOWN_SECTIONS` with a declarative schema supporting typed validation and list fields. Config validator at load time warns on unknown sections with the section name in the log message.

**Files:** `src/knarr/dht/plugins.py`, `src/knarr/cli/config.py`, `src/knarr/cli/config_schema.py`

**A-3: Explicit pool wrappers** (~70 LOC)

`to_protocol_thread(fn, *args)` and `to_handler_thread(fn, *args)` public async wrappers added to `DHTNode`. All protocol-critical sync calls updated to use `to_protocol_thread`; all handler-pool calls updated to use `to_handler_thread`. Pool hygiene test verifies no new direct `run_in_executor(None, ...)` calls in async paths of node.py.

**Files:** `src/knarr/dht/node.py`, `src/knarr/dht/pool.py`

**A-5: URI_LEGACY_CLIENT metric** (~100 LOC)

`task_requests_legacy_uri_count` counter added to `DHTNode._dashboard_metrics`. Incremented at `_handle_task_request_via_http` when an inbound TaskRequest carries no URI field (v0.55.0-era client). `URI_LEGACY_CLIENT` debug log emitted at the same site. `get_dashboard_metrics()` public accessor exposes the counter to cockpit and external monitors.

**Files:** `src/knarr/dht/node.py`

**A-6 / BCW-02: `_handle_payment_finalized` mint guard** (~15 LOC)

BCW plugin `_handle_payment_finalized` stub wired with a mint guard: `if mint_address != self._knarr_mint(): return`. Uses existing `TransferEvent.mint_address` field (already present) and the existing `_knarr_mint()` config accessor. Credits only proceed for the configured Knarr mint address.

**Files:** `src/knarr/plugins/10-bcw/handler.py`

### Track B — Security

**B-1: Sidecar 64 KB chunk loop** (~15 LOC)

`AssetSidecar._receive_asset` replaced single `await reader.readexactly(content_length)` with a 64 KB chunk loop. Prevents memory spikes on large asset transfers and removes the hard limit that caused `IncompleteReadError` on content > 64 KB.

**Files:** `src/knarr/dht/sidecar.py`

**B-4: CertPin reconnect rate limit** (~15 LOC)

`_cert_pin_reconnect_limit = 5` cap on per-IP reconnect attempts after `CertPinMismatchError`. Prevents a peer with a rotated cert (or an adversary spoofing cert rotation) from flooding the reconnect path. Counter reset on successful handshake.

**Files:** `src/knarr/dht/node.py`

**B-5: Fire-and-forget TLS verification** (~20 LOC)

`_send_fire_forget` path now passes `ssl=self._client_ssl_ctx` and calls `_check_peer_cert_fingerprint` after handshake, matching the verified send path. Previously, fire-and-forget connections bypassed TOFU cert checking entirely.

**Files:** `src/knarr/dht/node.py`

### Track C — Latent bugs

**C-1: `_split_statements` SQL migration splitter** (~15 LOC)

`migrations.py` gains `_split_statements(sql)` — splits multi-statement migration SQL on `;` boundaries while ignoring semicolons inside string literals. Prevents `OperationalError: incomplete input` on SQLite when a migration script contains multiple statements.

**Files:** `src/knarr/core/migrations.py`

**C-2: `@version` asymmetry fix** (~3 LOC)

`_resolve_target_identity` in node.py now strips the `@version` suffix from `skill_name` before lookup, matching the stripping already performed in `_validate_task_request_uri`. Callers sending `echo@1.0` now correctly resolve the identity route.

**Files:** `src/knarr/dht/node.py`

**C-3: PUNCHHOLE_ACL_DENY log string rename** (~4 LOC)

Log string `reason=unknown_and_no_public_signed_tier` renamed to `reason=unknown_not_in_trusted_nodes_or_peer` in both deny paths of `08-punchhole-frontend/handler.py`. The old string referenced a `public_signed` tier that does not exist in the codebase; operators grepping for it found no matching config key.

**Files:** `src/knarr/plugins/08-punchhole-frontend/handler.py`

**C-4: Stray `asyncio.get_event_loop()` removal** (~5 LOC)

Remaining bare `asyncio.get_event_loop()` calls in async node.py paths replaced with `asyncio.get_running_loop()`. Eliminates `DeprecationWarning` on Python 3.10+ and `RuntimeError` on Python 3.13 where `asyncio.run()` leaves no current event loop.

**Files:** `src/knarr/dht/node.py`

**C-5: WinError 10054 unification** (~10 LOC)

`_is_winerror_10054(exc)` helper added at module level in node.py. Three previously inconsistent `ConnectionResetError` / `OSError` catch sites unified to use the helper. Fixes silent swallowing of connection-reset errors on Windows in paths that only caught `ConnectionResetError`.

**Files:** `src/knarr/dht/node.py`

**C-6: .gitignore artifact coverage** (~2 LOC)

`*.sqlite3` pattern added to `.gitignore`. `*.db` was already present. Both `disclosure.db` and `bcw.sqlite3` are now covered by wildcard patterns.

**File:** `.gitignore`

**C-7: v0.56.0 release notes peer tier wording** (~6 LOC)

v0.56.0 release notes corrected: peer tier description updated from "active bilateral ledger entry" to "nodes that have either announced a skill (skill announce) or established a bilateral ledger relationship", matching actual `peer_keys` population logic.

**File:** `docs/releases/v0.56.0.md`

**C-9: Mail sync startup grace period** (~15 LOC)

`MailSync` circuit breaker grace period `_cb_grace_seconds = 30.0` added. On cold start, the circuit breaker does not open for the first 30 seconds regardless of failure count. Prevents the false-open state caused by transient delivery failures at startup before peer connections stabilize.

**Files:** `src/knarr/mail/sync.py`

**C-10: Sample binding bus event** (~5 LOC)

`security.sample_binding_strip` bus event emitted when a skill announce with a `samples` field is received and the samples fail AAD binding verification. Previously the failure was silent. Operators can subscribe to this event for audit.

**Files:** `src/knarr/dht/node.py`

### Track D — Event-loop blocking

**F-04: Settlement execution off the async loop** (~10 LOC)

`settlement_execution.py` wraps all blocking storage calls (`write_receipt`, `get_node_id_by_pubkey`, `get_ledger_balance`, `get_or_create_ledger_entry`) in `run_in_executor(None, ...)`. Settlement execution is an `async def` — the blocking ops inside it were the source of contention, not the call site.

**Files:** `src/knarr/commerce/settlement_execution.py`

**F-06: Write-queue sleep polling → asyncio.Event** (~30 LOC)

`_write_loop` `sleep(0.01)` polling replaced with `asyncio.Event`-driven wait. `_write_event: asyncio.Event` added to `DHTNode`. `_enqueue_write` and `_enqueue_write_proto` call `_write_event.set()` after queuing. `_wait_either_queue` waits on the event with a 1-second timeout fallback. Eliminates 100 wakeups/second idle overhead.

**Files:** `src/knarr/dht/node.py`

**F-07: `get_peers` calls via `to_protocol_thread`** (~20 LOC)

Five periodic-path `storage.get_peers()` call sites in node.py updated from direct sync call to `await self.to_protocol_thread(self.storage.get_peers)`. These were the last known synchronous storage calls on the async heartbeat sweep path.

**Files:** `src/knarr/dht/node.py`
