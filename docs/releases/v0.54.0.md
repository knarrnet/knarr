# Release Notes — v0.54.0 "URI Envelope + Warehouse Membrane"

**Date:** 2026-03-30
**Base:** v0.53.1

---

## Summary

The URI becomes the canonical address for all objects. Every message can carry a URI envelope. The Warehouse Membrane becomes an infrastructure plugin validating and routing by URI pattern. Punchhole queries drop from 10s (mail transport) to <100ms (PluginMessage transport). A generic `query_plugin()` RPC primitive enables any plugin to query any other plugin on any node.

## URI Envelope (E-01, E-02)

- **Envelope dataclass** with `uri`, `payload`, `signature`, `public_key`, `timestamp`, `trace_id`, `node_id`.
- **URI parser** (`core/uri.py`) — `parse_knarr_uri()` returns `(identity, selector, resource)`. 7 plugin selectors.

## Warehouse Membrane Plugin (E-03, E-04)

- **New plugin** at `plugins/00-warehouse-membrane/`. 5-gate validation pipeline.
- **Plugin priority** — load order control. WM loads first (priority 0).
- **contextvars** — `_current_identity` ContextVar replaces swap-and-restore. `@property` accessors on DHTNode.
- **`required = true`** — startup fails if required plugins don't load.
- **Commerce integration** — delegates `_wm_ingest()` for `knarr://*/c/*` patterns.

## query_plugin() Primitive (A-01)

- Generic remote plugin RPC on PluginContext. `_pending_rpcs` Future registry. SSRF-protected.

## Punchhole Transport Fix (P-01)

- `on_mail_received` → `on_inbound`. PluginMessage transport. <100ms vs 10s.

## Debug/Trace (A-02)

- `trace_id` correlation. Per-plugin `_debug`. WM gate trace logging.

## Other

- **P-02:** URI column on receipt_log.
- **S-01:** config_dir, WinError 10054, C3 circuit breaker deleted, identity emitters.
- **10 adversary TPs** fixed (SSRF, gate authorization, RPC origin validation, identity ordering).
