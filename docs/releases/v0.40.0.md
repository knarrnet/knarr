# Release Notes — v0.40.0 "Smioja" (Deferred Bus + Config Splitting, Adversary-Hardened)

**Date:** 2026-03-08
**Branch:** `feature/v0.40.0`
**Status:** Cluster gate pending

---

## Summary

Smioja ("The Forge") adds the deferred event bus primitive, config file splitting, and pricing engine formalization. The deferred bus is the architectural foundation for grace periods, scheduled holds, and time-delayed economic flows. Config splitting separates operator settings into tiered files with section enforcement. Five-model adversary panel (Opus, Sonnet, Gemini, GPT, Qwen — 167 attack tests) identified 14 deduplicated vulnerabilities across all tracks. 9 fixed, 4 deferred to v0.41.0, 1 documentation-only.

## Breaking Changes

None. All changes are backward-compatible. Single-file `knarr.toml` configurations continue to work unchanged.

## New: Deferred Bus Primitive (C1)

`EventBus.emit()` now accepts `valid_from` and `valid_until` parameters:

```python
event_id = bus.emit("credit.hold", valid_from=time.time() + 300,
                    valid_until=time.time() + 3600, peer="abc", amount=5.0)
```

- **`valid_from`** — event deferred until this timestamp. `tick()` fires matured events each heartbeat cycle.
- **`valid_until`** — event expires if not fired before this timestamp. Expired events are silently discarded by `tick()`.
- **`cancel(event_id)`** — removes a pending deferred event before it fires.
- **NaN/Inf guards** — non-finite timestamps rejected with warning log (adversary fix E).
- **Fire-outside-lock** — deferred events collect under lock, fire after lock release. Prevents re-entrant deadlock when subscribers emit new events.

This is the foundation for AP-05 (grace period composition): emit a deferred hold, cancel it when payment arrives, or let it fire if the grace period expires.

## New: Config File Splitting (B1)

Operator settings now support tiered TOML files loaded in priority order:

| File | Tier | Valid Sections |
|------|------|---------------|
| `knarr.toml` | Base (all sections) | `*` |
| `knarr.economy.toml` | Economy | `policy`, `pricing`, `economy`, `settlement` |
| `knarr.skills.toml` | Skills | `skills`, `exposures` |
| `knarr.mail.toml` | Mail | `mail` |

Tier files override base values via `deep_merge()`. Missing tier files are silently skipped.

Security controls:
- **Section enforcement** — sections outside a tier's valid set are stripped before merge with warning log (adversary fix F).
- **Per-tier key validation** — `_warn_unknown_keys()` runs on each tier file individually (adversary fix H).
- **Deep copy isolation** — `deep_merge()` uses `copy.deepcopy(base)` to prevent aliasing between base and merged dicts (adversary fix B).

## Change: Pricing Engine Carve-Out (B2)

Pricing dispatch formalized with config-driven engine selection:

```toml
[pricing]
engine = "builtin"  # or "module"
```

- **`builtin`** — existing `_resolve_price_builtin()` path in node.py
- **`module`** — delegates to `pricing_engine.py` module (if installed)
- **Input validation** — NaN, Inf, and negative `base_price` rejected at the dispatcher level before engine selection (adversary fix N).
- **Whitespace tolerance** — engine string normalized with `.strip().lower()` (adversary fix M).

## Fix: Heartbeat Timeout Cap (A1)

`_peer_heartbeat_sweep()` extracted from the heartbeat loop and wrapped with `asyncio.wait_for(timeout=PEER_HEARTBEAT_SWEEP_TIMEOUT)` (default 10s). Prevents slow/unreachable peers from blocking the entire heartbeat cycle indefinitely.

If the sweep times out, a `HEARTBEAT_SWEEP_TIMEOUT` warning is logged and the node continues operating. Skipped peers are retried next cycle.

## Fix: BCW Chain ID Tightening (A2)

- `startswith("solana")` changed to `startswith("solana-")` across all 5 call sites. Rejects bare `"solana"` and nonsense like `"solanaFAKE"` while accepting `solana-mainnet`, `solana-testnet`, `solana-devnet`.
- `isinstance(chain_id, str)` guard added to both free functions (`derive_counterparty_address`, `_derive_master_address`). `None` now raises `ValueError` instead of `AttributeError` (adversary fixes C, D).
