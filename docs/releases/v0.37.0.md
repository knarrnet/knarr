# Release Notes — v0.37.0 "Vordur" (The Security Membrane)

**Date:** 2026-03-05
**Branch:** `feature/v0.37.0`
**Status:** Released

---

## Summary

The Security Membrane: a multi-layer ingestion pipeline that validates every commerce document before it touches the ledger. Three new subsystems (Warehouse Manager, Punchhole Cache Manager, Blockchain Watcher), hardened by a 5-model adversary panel.

## New Modules

### Warehouse Manager (`src/knarr/core/warehouse_manager.py`)
5-gate document validation pipeline:
1. **Authenticity** — Ed25519 signature verification
2. **Addressing** — DID resolution, node identity checks
3. **Schema** — Commerce schema validation for all document types
4. **Integrity** — RFC 8785 canonical JSON hash verification
5. **Authorization** — Role-based access, cockpit sub-identity for configuration_order

Auto-promote for 7 document types: execution_receipt, payment_executed, wallet_withdrawal, settlement, transfer_event, netting_result, trade_receipt. Hold+approve flow for configuration_order.

### Punchhole Cache Manager (`src/knarr/plugins/08-punchhole-frontend/`, `09-punchhole-backend/`)
Two-plugin airgap architecture:
- **DMZ Frontend** (08) — validates requests, object_key regex gate, path traversal block, dict type guard, emits to event bus
- **LAN Backend** (09) — serves cached content, range control with NaN/Inf protection, startup idempotency guard

### Blockchain Watcher (`src/knarr/plugins/10-bcw/`)
On-chain event monitoring:
- Solana transaction watching with configurable confirmation depth
- Hex-validated address derivation from master seed + node_id
- SQLite event deduplication
- Solana RPC client (`solana.py`)

### Dynamic Skill Management (`src/knarr/cli/config.py`)
- `write_dynamic_skill()` / `load_dynamic_skills()` / `remove_dynamic_skill()`
- TOML injection protection via `_safe_toml_key()` and `_toml_escape()`

### Commerce Document Types (`src/knarr/commerce/`)
- `transfer_event.py` — new document type
- `schemas.py` — validators for netting_result, trade_receipt added
- `documents.py` — factories for all new document types
