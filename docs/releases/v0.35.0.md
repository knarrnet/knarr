# Release Notes — v0.35.0 "Bilateral Commerce"

**Date:** 2026-03-03
**Branch:** `feature/v0.35.0`
**Status:** Release candidate

---

## Summary

Bilateral commerce foundation. Two-layer receipt architecture with W3C Data Integrity signing, configurable admission gate, pricing engine with discount rules, and plugin bridge for Thrall v3.3 integration.

## New Modules

### Commerce Layer (`src/knarr/commerce/`)
- **documents.py** — Document class with type registry, validation, CloudEvents pattern. 8 document factories (execution_receipt, credit_note, order_ack, order_executing, mail_delivery_receipt, mail_receive_receipt, admission_decision, price_calculation).
- **receipt_writer.py** — Document-to-storage bridge. Optional eddsa-jcs-2022 signing. Fail-open design with bus event emission on failure.
- **admission_gate.py** — P-010 economic admission control. Four outcomes: accepted, soft_warning, hard_block, free_pass. NaN/Inf-safe.
- **pricing_engine.py** — Discount rules (multiplicative, additive, best_wins), caps, floors, cost projection. Input-validated.
- **admission_pipeline.py** — Orchestrates pricing + gate + receipt in a single call.
- **economy.py** — Peer economy state for self/info and cockpit. NULL-safe, inverted-config-aware.
- **plugin_bridge.py** — PluginContext sign_document + query_receipts. Closure-introspection-hardened via __slots__ callable classes. Wired into node.py post-load loop.

### Crypto Layer (`src/knarr/core/`)
- **rfc8785.py** — Vendored RFC 8785 JSON Canonicalization Scheme. NaN/Inf-rejecting.
- **proof.py** — eddsa-jcs-2022 sign/verify. Double-hash (proof-config-first). Base58btc encoding. Signature length validation.

### Patches
- **m015_tick_starvation.py** — Exception-safe bounded peer sweep with per-peer and overall timeouts.
- **o021_config_warnings.py** — Unknown config key warnings.
