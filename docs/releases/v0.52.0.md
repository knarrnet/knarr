# Release Notes — v0.52.0 "Node Durability"

**Date:** 2026-03-25
**Base:** v0.51.4

---

## Summary

Nodes self-degraded after sustained operation at 150+ nodes: 92 RPS against SQLite, 17K receipt_log rows in 18h, 2-8s event loop blocks per flush cycle, cockpit timeouts. This sprint fixes the structural issues with a new storage strategy plugin (caching, async I/O, archival, pruning) and core async I/O fixes.

**Results:** Cockpit latency 214ms → 5ms. RPS 92 → 741. Event loop blocks eliminated. Steady-state memory 73 MiB → 34 MiB (62 MB DB).

## Breaking Changes

- Plugin directory renamed: `plugins/00-kademlia/` → `plugins/01-kademlia/` (storage-strategy must load first)
- New plugin directory: `plugins/00-storage-strategy/` (must be deployed to existing nodes)
- `mail/handler.py`: `handle()` is now `async def` — callers must `await`

---

## New Plugin — `plugins/00-storage-strategy/`

### SA-01: StorageCache with TTL Invalidation
Read-through cache proxy wrapping `node.storage` via `__getattr__`. Eliminates ~95% of DB reads. Configurable TTLs per method family (peers: 30s, skills: 60s, economy: 10s). Prefix-based invalidation on writes.

### SA-02: Async Read Offload
Cache misses offloaded to `asyncio.to_thread`. WAL mode enables parallel readers. Sync fallback methods on Storage class for when plugin is not loaded.

### SA-03: Archive Rotation
Old rows archived to `{archive_dir}/{table}/{date}.jsonl.gz` before deletion. receipt_log and execution_log at 7-day retention.

### SA-04: Signed Encrypted Archives
Compress → encrypt (vault SecretBox) → sign (Ed25519). Tamper-evident, at-rest protected audit data.

### SA-05: Restore Utility
Verify signature → decrypt → decompress → temp table with column type preservation via `PRAGMA table_info()`.

### SA-06: Configurable Pruning
Per-table retention in plugin.toml with status filters. Prevents pruning pending settlements.

## Core Changes

### PRE-01: Storage Method Extraction
13 raw `_get_conn()` SQL calls extracted to named Storage methods. node.py, server.py, plugin_bridge.py now use storage API exclusively.

### Async I/O Fixes
- **C-01:** `flush_outbox` parallelized via `asyncio.gather` (was sequential per-recipient)
- **C-04:** `urllib.request.urlopen` wrapped in `asyncio.to_thread` (was blocking 10-15s)
- **C-05:** Sidecar file I/O wrapped in `asyncio.to_thread`

### Experiment Blockers
- **E-01:** Settlement debug flag (module-level `_debug` + `configure_debug()`)
- **E-05:** `/api/settlements` cockpit endpoint
- **E-06:** Recursive TOML dict serialization (was crashing on nested dicts)
- **E-08:** KAD fallback in `_select_execute_provider` for dynamic skills

### Infrastructure
- **D-01:** Consolidated fresh-install schema derived from in-memory migration run
- **F-01:** tracemalloc startup profiling (gated by `KNARR_TRACEMALLOC=1`)
